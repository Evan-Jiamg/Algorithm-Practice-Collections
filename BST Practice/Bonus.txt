Requirement : 

Basic

1. Insert an integer data in a binary search tree (BST). After the insertion, use a "recursive approach" to traverse the tree by the "inorder traversal" and print the traversed sequence, which should be in nondecreasing order.

	-> 在 "Element : " 欄位輸入欲插入的元素後，點選 "Recursive" 的 RadioButton，再按下 "插入元素" 的 Button，會自動跳至 "Tracing Record" 分頁，並於 Memo 顯示 Recursively Insertion 的 Inorder Sequence (Recursively) 結果。	

2. k integer data, which are generated randomly within a specified range assigned by the user, can be inserted into the BST. After these k integers are inserted, traverse the tree by "inorder sequence" and print the sequence.

	-> 在名為 "Insert 隨機產生數值 : " 的 GroupBox 內，先於 "輸入元素數量 : " 欄位，輸入欲生成多少個隨機數值，皆者於 "Range值域 : " 的 "最大值" 和 "最小值" 欄位，輸入隨機生成數值的最大值和最小值，最後再按下 "插入元素" 的 Button，會於 Memo 先顯示生成的 Random Sequence，再顯示 
Inorder Sequence (Recursively) 的結果。

3. Delete an integer number from BST (assigned by the user).

	-> 在 "Element : " 欄位輸入欲刪除的元素後，點選 "Recursive" 的 RadioButton，再按下 "刪除元素" 的 Button，會自動跳至 "Tracing Record" 分頁，若元素存在於 Sequence 內，會在 Memo 顯示 Recursively Deletion 後 Inorder Sequence (Recursively) 的結果，若元素不存在，則會顯示 "串列中並未有 X 數值，無法刪除!"。

4. Search a target integer in the BST.

	-> 在 "Element : " 欄位輸入欲搜尋的元素後，點選 "Recursive" 的 RadioButton，再按下 "搜尋元素" 的 Button，會自動跳至 "Tracing Record" 分頁，並且在 Memo 顯示 Recursively Searching Target 的結果，若 "X" 元素存在，會顯示 "X -> Found it!"，不存在時，則會顯示 "元素 : X 不存在!"。

5. Traverse the BST recursively to obtain the 

	5.1 inorder sequence (or infix);

	-> 在名為 "Traversal : " 的 GroupBox 內，點選 "Recursive" 的 RadioButton，再按下 "Infix" 的 Button，會自動跳至 "Tracing Record" 分頁，並於 Memo 顯示 Inorder Sequence (Recursively)。

	5.2 preorder sequence (or prefix);

	-> 在名為 "Traversal : " 的 GroupBox 內，點選 "Recursive" 的 RadioButton，再按下 "Prefix" 的 Button，會自動跳至 "Tracing Record" 分頁，並於 Memo 顯示 Preorder Sequence (Recursively)。

	5.3 postorder sequence (or postfix);
	
	-> 在名為 "Traversal : " 的 GroupBox 內，點選 "Recursive" 的 RadioButton，再按下 "Postfix" 的 Button，會自動跳至 "Tracing Record" 分頁，並於 Memo 顯示 Postorder Sequence (Recursively)。

6. Traverse the BST to obtain the levelorder sequence.

	-> 按下 "Level-Order Traversal" 的 Button，會自動跳至 "Tracing Record" 分頁，並在 Memo 顯示 Sequence 結果。

Advanced

1. Traverse the BST non-recursively to obtain the 

	1.1 inorder sequence;
		
	-> 在名為 "Traversal : " 的 GroupBox 內，點選 "Non-Recursive" 的 RadioButton，再按下 "Infix" 的 Button，會自動跳至 "Tracing Record" 分頁，並於 Memo 顯示 Inorder Sequence (Non-Recursively)。

	1.2 preorder sequence;

	-> 在名為 "Traversal : " 的 GroupBox 內，點選 "Non-Recursive" 的 RadioButton，再按下 "Prefix" 的 Button，會自動跳至 "Tracing Record" 分頁，並於 Memo 顯示 Preorder Sequence (Non-Recursively)。

	1.3 postorder seqeunce.

	-> 在名為 "Traversal : " 的 GroupBox 內，點選 "Non-Recursive" 的 RadioButton，再按下 "Postfix" 的 Button，會自動跳至 "Tracing Record" 分頁，並於 Memo 顯示 Postorder Sequence (Non-Recursively)。

2. Non-recursively insertion 

	-> 在 "Element : " 欄位輸入欲插入的元素後，點選 "Non-Recursive" 的 RadioButton，再按下 "插入元素" 的 Button，會自動跳至 "Tracing Record" 分頁，並於 Memo 顯示 Non-recursively 插入的 Inorder Sequence (Recursively) 結果。

3. Non-recursively deletion

	-> 在 "Element : " 欄位輸入欲刪除的元素後，點選 "Non-Recursive" 的 RadioButton，再按下 "刪除元素" 的 Button，會自動跳至 "Tracing Record" 分頁，若元素存在於 Sequence 內，會在 Memo 顯示 Non-recursive Deletion 後 Inorder Sequence (Recursively) 的結果，若元素不存在，則會顯示 "串列中並未有 X 數值，無法刪除!"。

4. Non-recursively searching target

	-> 在 "Element : " 欄位輸入欲搜尋的元素後，點選 "Non-Recursive" 的 RadioButton，再按下 "搜尋元素" 的 Button，會自動跳至 "Tracing Record" 分頁，並且在 Memo 顯示 Non-recursively Searching Target 的結果，若 "X" 元素存在，會顯示 "X -> Found it!"，不存在時，則會顯示 "元素 : X 不存在!"。

5. Draw BST

	-> 在插入完元素後，按下 "Draw BST" 的 Button，會自動跳至 "Binary Tree Drawing" 分頁，顯示 BST 的樹狀圖。

6. 新增 "Clear BST" 的 Button
	
	-> 按下 "Clear BST" 的 Button 後，會清除所有 Edit 欄位的內容、取消所有已選擇的 RadioButton、清除 "Tracing Record" 分頁上 Memo 的內容和 "Binary Tree Drawing" 分頁的 BST 樹狀圖。

7. 防呆機制

	7.1 在 "Element : "、"輸入元素數量 : "、"最大值 -> " 和 "最小值 -> " 欄位，若輸入非整數數值，會於 "Tracing Record" 分頁顯示警告訊息。
	
	7.2 若在 "最大值 -> " 欄位輸入的數值小於 "最小值 -> " 欄位的數值，則會於 "Tracing Record" 分頁顯示警告訊息。

	7.3 若在 "輸入元素數量 : " 輸入的元素數量小於 Rang值域的 "最大值" 減去 "最小值" 時，會生成 (最大值-最小值) 所能生成的最多不重複的數值，而不會生成重複的數值或出現錯誤。

	7.4 在 "Element : " 欄位輸入已經有的數值於 Sequence 上時，並按下 "插入元素" Button後，會於 "Tracing Record" 分頁顯示警告訊息。

	7.5 未插入元素於 Sequence，並直接按下 "Prefix"、"Infix"、"Postfix" 和 "Level-Order Traversal" 按鈕，會於 "Tracing Record" 分頁顯示警告訊息。

	7.6 尚未點選使用 Recursive 或 Non-Recursive 方法的 RadioButton 選項，直接按下 "插入元素"、"刪除元素"、"搜尋元素"、"Prefix"、"Infix" 和 "Postfix" 按鈕，會於 "Tracing Record" 分頁顯示警告訊息。
