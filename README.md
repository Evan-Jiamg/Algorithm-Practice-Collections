# Algorithm-Practice-Collections

> C++ Builder 演算法與資料結構實作集，均具備 GUI 視覺化介面

![C++](https://img.shields.io/badge/C++-7F77DD?style=flat-square&logo=cplusplus&logoColor=white)
![C++ Builder](https://img.shields.io/badge/C++_Builder_(VCL)-378ADD?style=flat-square)

## Overview

以 C++ Builder VCL 框架實作的 Algorithm & Data Structures 練習集，涵蓋排序、圖論、樹狀結構、回溯演算法...等主題。每個專案均附有 GUI 視覺化介面和輸入防呆機制，方便直觀觀察演算法執行過程。

## Projects

### 圖論 / Graph

| Project | Description |
|---|---|
| [Knight Tour](./Knight%20Tour) | Warnsdorff's heuristic 實作騎士巡邏，視覺化完整路徑 |
| [MST (Kruskal & Prim)](./MST%20(Kruskal%20%26%20Prim)) | Kruskal 與 Prim 演算法效能比較，含執行時間統計 |
| [Maze Tracing](./Maze%20Tracing) | Stack 回溯法求解迷宮，視覺化解題路徑 |

### 回溯 / Backtracking

| Project | Description |
|---|---|
| [N-Queen Problem](./N-Queen%20Problem) | N-Queen 全解枚舉，逐步顯示所有合法擺放方式 |
| [Matrix Tracing (with SSAD)](./Matrix%20Tracing%20(with%20SSAD)) | 矩陣路徑追蹤，含 SSAD 結構分析 |

### 資料結構 / Data Structures

| Project | Description |
|---|---|
| [BST Practice](./BST%20Practice) | Binary Search Tree 插入、刪除、走訪視覺化 |
| [Linked Stack & Queue](./Linked%20Stack%20%26%20Queue) | Linked List 實作 Stack 與 Queue，動態展示節點操作 |
| [Infix - Postfix - Prefix](./Infix%20-%20Postfix%20-%20Prefix) | 三種運算式表示法互轉，含 Stack 運算過程展示 |

### 數學 / Math

| Project | Description |
|---|---|
| [Addition of Polynomial](./Addition%20of%20Polynomial) | 多項式相加，Linked List 儲存結構 |
| [Power and Polynomial](./Power%20and%20Polynomial) | 多項式求值與冪次計算 |
| [Sorting Algorithm Comparison](./Sorting%20Algorithm%20Comparison) | 多種排序演算法效能比較，含執行時間視覺化圖表 |

## Environment

- 所有專案以 **C++ Builder（Embarcadero RAD Studio）** 開發，使用 VCL 框架建構 GUI。
- 開啟方式：以 C++ Builder 開啟各資料夾內的 `.cbproj` 檔案即可執行。
